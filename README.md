# SeeUSoon
Calendar-syncing dating app for college students - validate demand before scaling

## Features
- .edu email verification (any college)
- Calendar sync to show mutual free time
- AI-powered conversation starters
- Privacy-first matching

## Tech Stack
- Frontend: React + TypeScript + Tailwind CSS
- Backend: Node.js + Express
- Database: PostgreSQL
- Mobile: Progressive Web App (PWA)

## Getting Started

### Backend
```bash
cd backend
npm install
npm run dev
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```
